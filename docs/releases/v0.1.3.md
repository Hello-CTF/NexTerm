## 本次更新

### 新增

- **默认内置「当前设备」资产** —— 装好即有一台本机资产，自带本地终端与工作区，
  不用再自己「新建资产」。（本机资产在左栏带 **本机** 徽标，不可删除、类型不可更改；
  可在资产编辑框里配置默认 Shell 与起始目录。）
- **容器 / 镜像支持批量操作** —— 列表新增勾选列、表头全选（含半选态）与选中计数，
  可一次删除多个容器或多个镜像。

### 修复

**容器 / 镜像管理**

- 切到「容器」标签后，**镜像行会残留在容器表里**（表头是容器的，行却是镜像的）。
- 同一镜像挂多个 repository 时（例如 `mysql:8.0` 与 `docker.m.daocloud.io/library/mysql:8.0`），
  列表会出现**重复行**。
- 删除镜像时传的是 image ID，被多个 repository 引用时会被 Docker 直接拒绝。
- 删除失败**没有任何提示**，看起来像没生效，于是反复点击 —— 现在有错误说明、
  乐观更新与行级禁用，删除不再有延迟感。

**AI 助手**

- **确认卡片永久转圈、文件不落盘、停止按钮失效** —— 一个自死锁，已修并补回归测试。
- **写入过程看不见** —— 模型生成工具参数期间界面零事件，写长内容时几十秒静默像卡死，
  现在有实时进度反馈。
- **智谱（`glm-*`）下进度条永远不亮** —— 上游默认把工具参数整块下发，已按厂商开启流式。
- **「文件变更可审」漏掉新建文件** —— 新建文件的修改前后对照整条消失；确认卡片现在先给出 diff。
- **门禁导致的重复生成** —— `write_file` 的说明漏写「必须先读文件」，模型看不见规则，
  会把整份内容生成完才被拒、然后重写一遍。已补全说明，并把检查提前到确认卡片之前。

**终端**

- 本地终端里**中文文件名显示成 `?`** —— GUI 启动的进程缺少 locale，已注入 `C.UTF-8`。

**SFTP**

- **改写远端已有文件必然失败**，且报错是「No such file」（方向完全错误）；
  副产品是备份文件为空。已修复，并补上使用真实 OpenSSH 的回归测试。

### 行为调整

以下两项在本机会话下**按设计不适用**，入口已置灰并说明原因，不再是「点了才失败」：

| 能力 | 本机会话 | 原因 |
|---|---|---|
| 端口转发 | 不适用 | 本机就是目标机器，转发没有意义 |
| 磁盘挂载 | 不适用 | 本机文件直接在左栏文件树里看，无需挂载 |

### 已知限制

- 本机会话没有重连语义（本地连接不会像 SSH 那样断线重连）。
- Linux 平台尚未验收；当前支持 Windows（基线）与 macOS。
