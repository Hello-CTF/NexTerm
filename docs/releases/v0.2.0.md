## 本次更新

**v0.2.0 —— 「一个内核，两种形态」。**

NexTerm 第一次有了**桌面之外**的形态。同一份内核（132 条命令，桌面与服务端共用同一份清单，
不是两套实现）现在也能跑在没有桌面、没有 WebKit 的 Linux 容器里，用浏览器访问 ——
它既是懒猫微服专版的底座，也可以直接装在你自己的 Linux 机器上。两种形态之间还能把资产
（含加密凭据）**手动、定向**地搬过去。

自 v0.1.3 以来共 31 个提交、164 个文件（+17119 / −854 行）。

### 新增

#### 一、浏览器版：打开浏览器就是一个运维工作台

终端、SFTP 文件、Docker、数据库、AI 助手都在，操作手感与桌面版一致 —— 因为前端就是同一份，
只是把进程间调用落到了 HTTP / WebSocket 上。连接时的凭据仍然加密存在你自己那台机器上。

- 终端字节走**二进制帧**，不走 base64（后者体积要涨三分之一）。
- **文件搬运**是这块最不显然的地方：浏览器手里只有「字节」，而内核只认「路径」。
  中间由服务端开一个**受控暂存区**做兑换（上传 → 暂存 → 交付 → 丢弃）；
  私钥这类要长期留的落另一个目录、不清扫，普通中转文件 2 小时后自动清理。
- 接入**懒猫网盘文件选择器**：打开 / 保存文件走微服网盘，而不是浏览器那个下载目录。

#### 二、懒猫微服专版（应用商店）

已打成 LPK v2 并**提交商店审核**；通过后在微服「应用中心」里直接安装，不经 Release 下载。

- 只把 **`/sync/rpc` 一条路径**交给应用自己鉴权，页面与其余接口照旧要过平台的账密。
  这条放行是必须的：微服公网入口对任何请求一律 307 到登录页、且**不认第三方请求头**，
  桌面端拿服务端生成的令牌去连，请求根本到不了容器。
- 商店要求的**网盘文件选择器**已接入（有上传下载能力就必须走平台规范）。

#### 三、资产同步（桌面 ↔ 服务端）

设置 → 「同步」。桌面机与服务端是两个独立实例（各自一份数据库），这一步把资产记录在两者
之间搬过去 —— **手动、显式定向、可勾选**。

- **四态对比表**：本地与远端的摘要合成「仅本机 / 仅对端 / 两边都有 / 完全相同」，
  默认勾中「只在一侧存在」的条目。这就是「同步哪些资产」的落点。
- 方向由**两个按钮**决定：推送 / 拉取。勾选框只表示「参与这次同步」。
- 两边都改过的条目**默认不覆盖**，要覆盖较新的一份得另外勾「强制覆盖」。
- 搬完给回执：资产与凭据各自新建 / 更新了几条，**跳过**与**警告**逐条列出。
- 凭据怎么过河：源端解密 → TLS → 目标端用**自己的**密钥重新加密。密文永远不能直接移植
  （两端的密钥派生自不同的根）。源端凭据库没解锁会明确报错，不静默跳过。
- 写入顺序按外键决定（分组 → 凭据 → 资产），分组内部还要父先于子；包来自对端、不可信，
  所以带环路守卫；「缺分组 / 缺凭据」这类悬空引用会**降级并警告**，不会整包失败。
- **按设计不同步**：AI 对话记录、审计日志、终端录像（都属本地行为记录），
  以及 known_hosts（必须反映目标机器真实的密钥，收下对端的指纹等于把这道防护关掉）。

> ⚠️ **同步过去的密码，接收端读得到。** 凭据在传输时是明文（在 TLS 之内），落到对端后
> 用对端的密钥重新封；服务端始终持有自己的根密钥。所以这项**默认不勾**
> —— 只搬资产记录本身；要连密码 / 私钥一起搬，再勾上「含凭据（密码 / 私钥）」。

#### 四、凭据侧边栏

左栏多了第三个形态：列表 + 类型过滤 + **只读镜像视图**（文本 / JSON，纯前端拼装，不含明文）。

顺带理了私钥与口令的存放方式：口令不再是可单独新建的类型，它与私钥存**同一条**凭据，
私钥来源二选一。旧数据照旧读得出来（非 JSON 一律按旧格式处理），**零迁移**。

#### 五、服务端命令行，以及 onlyServer

`nexterm-server` 有了完整命令行：子命令 `serve` / `token` / `rotate-token`，
选项 `--sync-only` / `--listen` / `--data-dir` / `--web-root` / `--master-key`。
**不带子命令就是 `serve`**，每个选项也都能用 `NEXTERM_*` 环境变量给。

`--sync-only` 即「**onlyServer**」形态：只挂 `/sync/rpc` 与 `/healthz`，
命令表从 132 条缩到 **3 条**（`sync_digest` / `sync_export` / `sync_import`，
也就是对端真正会调的那三条）。

这不是省事做法，而是「**这台机器只该被信任做这一件事**」：
`/sync/rpc` 的令牌走的是同一张命令表，全量注册时「同步令牌」等价于「本实例的完全控制权」
—— 拿到它就能开终端、读写任意文件、操作 Docker、读凭据库。缩到 3 条之后，
令牌即便泄漏，后果也被限制在「能读写这份资产库」。

`token` 之所以是子命令而不是界面按钮，是因为 **onlyServer 没有界面**，
否则用户只能去改数据库才能看到令牌。取令牌时只有令牌本体进标准输出、说明进标准错误，
所以 `TOKEN=$(nexterm-server token)` 可以直接用。

另外两处细节：`--listen` 写错格式会**直接报错退出**（旧行为是警告一句、然后照常绑到
`0.0.0.0:8080` —— 在命令行场景下这等于「手滑打错一个字符，服务被公开到公网」）；
监听非回环地址时会打印醒目警告，**同时写标准错误**，终端与 `journalctl` / `docker logs` 都看得见。

#### 六、图标换成真透明底

原来那版是实底方砖，在 Dock / 任务栏 / 商店卡片上会显出一个黑方块。这版做成真透明底，
并重出了全套尺寸（macOS `.icns` / Windows `.ico` / 各尺寸 PNG，共 54 个文件）。

### 修复

**会话稳定性（长期开着最需要的一条）**

- **断开后无法重连** —— 以前「断开」与「回收」是同一件事，会话对象连同标签一起被丢掉，
  重连时没有原料重建。现在拆成两个动作：断线只关传输、保留会话与标签；真正的销毁
  只留给本机、数据库这类没有重连语义的会话。
- 掉线**自动重连**（退避重试），并且区分「关标签」「敲了 exit」「真掉线」——
  只有真掉线才重连，正常退出不会莫名其妙又连上去。
- 会话失效后点「新建终端」会按**同一台主机**重连，不再退化成开「当前设备」。

**桌面打包会装错主程序（未流出，已发布的 0.1.3 不受影响）**

项目里多了第二个可执行文件之后，打包工具挑中的是服务端那个 —— 而它在桌面构建里只是个
323 KB 的桩（打印一句「当前是桌面模式构建」就退出）。打出来的 `.app` / `.exe` 里主程序
就是它，装上点开即退。给服务端入口加上 feature 约束后消失。
**受影响的只是开发中间态，v0.1.3 放出去的安装包是好的。**

**其他**

- 连接懒猫微服时「跳过证书校验」的提示**说反了**：原话是「不勾会握手失败」，但真机确认
  公网地址用的是 Let's Encrypt 证书，那种地址**不用**勾。现在只对自签证书的地址提示。

### 已知限制

- **懒猫微服专版仍在商店审核中**，通过之前只能用下面的 Linux 包自行部署。
- **同步是手动的**：没有自动同步，也没有后台定时同步。
- **浏览器版完整形态不适合直接暴露公网**：它自身没有登录鉴权（懒猫上那道登录门是平台给的，
  裸 Linux 上没有）。公网场景请用 onlyServer。
- **自建服务端要自己给根密钥**（`--master-key` 或 `NEXTERM_MASTER_KEY`，至少 8 位）。
  不给不是起不来，而是**凭据库保持未初始化** —— SSH 密码类资产不可用，同步密码类凭据会失败。
  懒猫微服上这一步由平台自动注入，不用管；`/healthz` 里能看到凭据库状态，可自查。
- 端口转发需要 **SSH 会话**（「本机 / 当前设备」这类会话下没有意义，入口已置灰并说明原因）；
  磁盘挂载需要平台授予「挂载 FUSE 文件系统」权限，未授权时入口置灰并给出原因。
- **Linux 桌面版尚未验收**；桌面端目前支持 Windows 10/11（基线）与 macOS（Apple Silicon）。
- 升级到本版**不涉及数据库结构变更**，装上新版即可，原有数据直接沿用。
