## 本次更新

**v0.2.2-rc.1 —— 首个 Go/Wails 预发布。**

从这一版起，NexTerm 从 Rust/Tauri 整体重写为 **Go + Wails v3**：目标是同一形态 ——
SSH / SFTP / Docker / 数据库一体化运维终端，桌面客户端与浏览器服务端两种形态、同一套内核。
构建、打包与发布流水线随之全部重做。

这是重写后的**第一个候选版本（release candidate）**，先放出来收集真实环境反馈，
稳定后再发正式版。**不承诺与 v0.2.1（Rust 版）的完整功能对齐**，差异与缺口欢迎反馈。

### 预发布须知

- 这是候选版，不是正式版；从 Rust 版（≤ v0.2.1）升级前请**先备份数据目录** ——
  这是重写后的第一版，不承诺与旧版数据库逐字段兼容。
- 本版尚未完成真实外部目标验收（各平台真机安装、懒猫微服商店上架仍在流程中）；
  Release 页附带的产物证据（SHA-256、格式/架构断言）可用于自行校验。
- 与官方 Rust v0.2.1 同形态产物的体积对照仅作参考信息，不设门槛，也不作为发布依据。
- Linux 服务端包要求 `glibc >= 2.38`（Ubuntu 24.04+ / Debian 13+）。
- 懒猫微服专版不经此页下载（在微服「应用中心」安装），其上架状态以商店为准。

### 已知限制

- **同步仍然是手动的**：没有自动同步，也没有后台定时同步。
- **浏览器版完整形态不适合直接暴露公网**：它自身没有登录鉴权。公网场景请用包内可选的
  `--sync-only` restricted 运行时并终止 TLS。
- 完整版服务端**自身没有登录鉴权**，不建议直接暴露公网。
